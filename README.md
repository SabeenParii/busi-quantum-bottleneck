# BUSI quantum-bottleneck study (pre-specified protocol)

Author: Sabeen Parii

* `protocols/PROTOCOL_busi_prespecified.txt`: the analysis plan, fixed before any training run
* `src/`: state-vector simulator (`qsim.py`), models, training and audit (`qbus.py`), data preparation (`prep.py`), run list and lock files (`runner.py`)
* `tests/test_qsim.py`: simulator checks (NumPy)
* `notebooks/00_data_prep.ipynb`, `notebooks/01_train.ipynb`: Google Colab notebooks

No image data are stored in this repository. BUSI, BUS-BRA and BrEaST-Lesions_USG are downloaded from their original sources (see the protocol, Section 2).
